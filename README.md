# Hospital Patient Management System

## Overview
This project demonstrates SQL fundamentals by designing and managing a Hospital Patient Management System database. It covers database creation, data insertion, CRUD operations, joins, aggregate functions, and query optimization using SQL.

## Objectives
- Design a relational database
- Store patient and doctor information
- Manage appointments
- Practice SQL queries
- Understand database relationships

## Technologies Used
- SQL
- MySQL

## Files
- schema.sql
- insert_data.sql
- basic_queries.sql
- joins.sql
- aggregate_functions.sql
- advanced_queries.sql
